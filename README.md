# ネギリタイプ

タイピングがうまいほど買い物が安くなる、ひと月のやりくりゲーム（unityroom 向け WebGL）。

## いまの段階：段階2（1回の買い物）

難易度を選び、店内でカートに入れた商品をレジで1品ずつ打って会計します。
財布が足りなければ返品し、最後にレシートで節約額を見ます。
確認したいのは「1回の品数と所要時間が疲れないか」です。
日付・在庫・満足度・セーブ・借金は段階3以降です。

### はじめ方

1. Unity Hub で **Unity 6 LTS** をインストールし、「Add project from disk」でこのフォルダーを開く。
2. 空のシーンのまま再生（▶）すると、タイトル画面が出る。

### 遊び方の流れ

1. タイトルで難易度を選ぶ。財布に試作用の3,000円が入る。
2. 店内で商品をカートに入れる（品数の上限は初級4・中級7・上級12・達人12品）。
3. レジでカートの商品を1品ずつ打つ。評価に応じて値引きされる。1品ごとの結果は5秒出て、自動で次の商品が始まる。
4. 全品打ち終えたら会計。財布が足りないときは返品する。
   - 初級：返品する商品を自分で選ぶ（ペナルティなし）
   - 中級：返品する商品を自分で選ぶ（1品ごとに満足度−3、段階2では記録のみ）
   - 上級：支払額（割引後）の高い順に自動で返品（同上）
   - 達人：支払額（割引後）の安い順に自動で返品（同上）
   - 自動返品は、同じ金額なら後からカートに入れた商品から。返品される商品と金額を確認してから会計する。
5. レシートで、商品ごとの評価・割引・支払額と、今回の節約額、財布の残高の変化を見る。

### 操作

決定はすべてスペースキーです。

| 画面 | キー | 動作 |
| --- | --- | --- |
| タイトル | ← / →（または 1〜4） | 難易度（初級・中級・上級・達人） |
| タイトル | ↑ / ↓、スペース | 「買い物をはじめる」か「タイピング練習」を選んで決定 |
| 店内 | ← / → | 売り場（食料・日用品・お菓子と趣味）とカートを行き来する |
| 店内（売り場） | ↑ / ↓、スペース | 商品を選んでカートに入れる |
| 店内（カート） | ↑ / ↓、スペース | 商品を棚に戻す／一番下の「レジへ進む」で会計へ |
| 店内 | Esc | タイトルへ |
| レジ | スペース | 1品目を開始（2品目からは自動で始まる） |
| レジ | R | 読みがなを出す・隠す（上級・達人のみ。開始前か結果表示中） |
| レジ（結果） | スペース | 5秒待たずに次の商品へ／会計へ |
| 返品（初級・中級） | ↑ / ↓、スペース | 返品する商品を選ぶ・取り消す／一番下の「会計する」で会計 |
| 返品（上級・達人） | スペース | 表示された内容で返品して会計 |
| レシート | ← / →、スペース | 「もう一度買い物」か「タイトルへ」 |
| タイピング練習 | スペース | 開始／次の商品 |
| タイピング練習 | Esc | 打っている途中は飛ばす。開始前と結果表示中はタイトルへ |

日本語入力がオンのまま打つと注意が出るので、半角英数に切り替えてください。

### 調整できる数値

- `Assets/Resources/Data/balance.json` の `shopping`：最初の財布の金額、レジの結果を出す秒数（`resultSeconds`）、難易度ごとの品数の上限・不足時の扱い・返品1品で減る満足度。
- `Assets/Resources/Data/stores.json`：店舗と特売（割引はベーシスポイント。1000 = 10%）。
- `Assets/Resources/Data/items.json` の `effects`：商品の効果（段階2では店内に表示するだけ）。

### 日本語フォントについて

WebGL ビルドでは日本語フォントを同梱する必要があります。
`Assets/Resources/Fonts/main.ttf`（またはotf）にフリーの日本語フォントを置くと、それが使われます（未定）。

## フォルダー構成

- `Assets/Scripts/Core` … ローマ字判定・評価・価格計算、財布・カート・会計・返品など。Unity に依存しない C#。
- `Assets/Scripts/Game` … 画面と進行。`ShoppingFlow` が進行役で、`Screens/` に各画面、`Ui/` に共通部品。
- `Assets/Resources/Data` … 商品・文章・調整値の JSON。
- `Assets/Tests/EditMode` … Core のテスト。
- `tools/CoreTests` … 同じテストを Unity なしで動かす .NET プロジェクト。

## テスト

- Unity：Window > General > Test Runner の EditMode。
- Unity なし：`dotnet test tools/CoreTests`（.NET 8 SDK が必要）。GitHub Actions でも自動実行。
