# ネギリタイプ

タイピングがうまいほど買い物が安くなる、ひと月のやりくりゲーム（unityroom 向け WebGL）。

## いまの段階：段階3-1（30日間）

難易度を選び、30日間のやりくりをします。月初に予算を受け取り、毎日マイルームで「買い物に行く」「家で過ごす」などを選びます。
買い物は段階2と同じく店内 → レジ → 返品 → レシートです。夜に食料と日用品の在庫が減り、満足度が変わります。
1日の終わりに自動でセーブされ、ブラウザを閉じても「つづきから」で再開できます。
確認したいのは「食料と予算のやりくりに悩むか」「中断と再開が自然か」です。
借金は段階3-2、朝のイベント・月末の決戦タイピングと採点は段階4です。

### はじめ方

1. Unity Hub で **Unity 6 LTS** をインストールし、「Add project from disk」でこのフォルダーを開く。
2. 空のシーンのまま再生（▶）すると、タイトル画面が出る。

### 遊び方の流れ

1. タイトルで難易度を選んで「はじめから」。セーブがあれば「つづきから」も選べる（はじめからにすると、確認してからセーブを上書きする）。
2. 月初：予算19,000円が財布に入る。目標商品（12,000円のバッグ）を見て、貯金箱（目標商品のためだけのお金、ゲーム内部では lock）に入れる額を決める（取り出せない）。貯金箱は合計6,000円まで（目標の半分）で、目標の残りは月末の財布から払う。
3. マイルーム：在庫・満足度・次に買い物できる日・今日の特売を見て、行動を選ぶ。
   - 1 買い物に行く（難易度ごとの頻度：初級は毎日、中級は3日に1回、上級・達人は7日に1回）
   - 2 家で過ごす（1日進む）
   - 3 数日進める（次に買い物できる日か、在庫が切れる日の朝か、月末まで）
   - 4 家計簿（買った物の一覧、支出と節約額、貯金箱への追加）
   - 5 中断する（タイトルへ。その日の朝から再開できる）
4. 買い物：店内の下に「全部買うと　食料 3→7日分」のように在庫と満足度の変化が出る。食料の上限（初級・中級7日分、上級・達人10日分）を超えた分はムダになる。
5. レシートの後は夜：食料と日用品が1日分ずつ減り、満足度が1下がる。在庫が0の夜は「在庫切れ」になり、満足度が食料で−8、日用品で−4下がる。
6. 30日目の夜の後に、月末のまとめ（残金・在庫切れの日数・満足度・節約額）が出る。

満足度は自由商品（お菓子・雑誌）で上がり、返品で下がる（中級以上、1品−3）。特売は曜日で変わる（火：卵・キャベツ、金：豚肉・チョコ、日：お米・洗剤）。

### 操作

決定はすべてスペースキーです。

| 画面 | キー | 動作 |
| --- | --- | --- |
| タイトル | ← / →（または 1〜4） | 難易度（初級・中級・上級・達人） |
| タイトル | ↑ / ↓、スペース | はじめから／つづきから／タイピング練習 |
| 月初 | ← / → | 貯金箱に入れる額を1,000円ずつ変える。スペースで決定（入れるときはもう一度スペースで確定） |
| マイルーム | ↑ / ↓（または 1〜5）、スペース | 行動を選ぶ |
| 店内 | ← / → | 売り場（食料・日用品・お菓子と趣味）とカートを行き来する |
| 店内（売り場） | ↑ / ↓、スペース | 商品を選んでカートに入れる |
| 店内（カート） | ↑ / ↓、スペース | 商品を棚に戻す／一番下の「レジへ進む」で会計へ |
| 店内 | Esc | 何も買わずに家へ帰る（その日はまだ買い物に行ける） |
| レジ | スペース | 1品目を開始（2品目からは自動で始まる） |
| レジ | R | 読みがなを出す・隠す（上級・達人のみ。開始前か結果表示中） |
| レジ（結果） | スペース | 5秒待たずに次の商品へ／会計へ |
| 返品（初級・中級） | ↑ / ↓、スペース | 返品する商品を選ぶ・取り消す／一番下の「会計する」で会計 |
| 返品（上級・達人） | スペース | 表示された内容で返品して会計 |
| レシート | ↑ / ↓ | レシートをスクロール（長いとき） |
| レシート | スペース | 家に帰って夜へ |
| 夜 | スペース | 次の朝へ（月末なら月末のまとめへ） |
| 家計簿 | ↑ / ↓ | 一覧をスクロール |
| 家計簿 | ← / →、スペース | 貯金箱に入れる額を決めて入れる（もう一度スペースで確定） |
| 家計簿 | Esc | マイルームへ戻る |
| 月末のまとめ | ↑ / ↓、スペース | もう一度（同じ難易度ではじめから）／タイトルへ |
| タイピング練習 | スペース | 開始／次の商品 |
| タイピング練習 | Esc | 打っている途中は飛ばす。開始前と結果表示中はタイトルへ |

日本語入力がオンのまま打つと注意が出るので、半角英数に切り替えてください。

### セーブ

- 月初に貯金箱の額を決めたとき、毎晩の終わり、家計簿で貯金箱に追加したときに自動で保存します。買い物の途中でやめると、その日の朝からやり直しです。
- 保存先は PlayerPrefs（WebGL ではブラウザ内）で、キー名は `negiri_type.save` です。セーブは1つだけです。
- Unity エディタでセーブを消したいときは、Edit > Clear All PlayerPrefs。

### 調整できる数値

- `Assets/Resources/Data/balance.json`
  - `life.month`：日数、月の予算（19,000円）、1日目の曜日、レシートに書く月、貯金箱に入れる単位、貯金箱の上限（`lockStartMax` 月初に入れられる額、`lockDailyMax` 家計簿から1日に入れられる額、`lockTotalMax` 合計。いまはすべて6,000円）、目標商品の名前と価格。
  - `life.stock`：食料・日用品の初期値、1日の消費、日用品の上限、在庫切れの夜に減る満足度。
  - `life.satisfaction`：満足度の初期値・上限・月末の目標・毎晩減る量。
  - `shopping.difficulties`：難易度ごとの品数の上限、買い物の間隔（`shopIntervalDays`）、食料の上限（`foodCap`）、不足時の扱い、返品1品で減る満足度。
  - `shopping.startingCash` は段階2の試作用で、今は使っていません。
- `Assets/Resources/Data/stores.json`：店舗と特売。`days` に曜日（例：`"火金"`）を書くとその曜日だけ、空なら毎日。割引はベーシスポイント（1000 = 10%）。
- `Assets/Resources/Data/items.json` の `effects`：商品の効果（食料＋○日、日用品＋○日、満足度＋○）。
- `Assets/Resources/Data/sentences.json`：レジで打つ商品名。`level` は 1＝初級、2＝中級、3＝上級、4＝達人。約1,500個あり、各商品・各レベルに13個以上。同じ商品の商品名は、候補を一通り出し切るまで同じものを出しません。`id` に `_g` が付くものは `tools/SentenceGen/generate_sentences.py` で語の組み合わせから作ったもので、スクリプトを直して実行すると作り直せます（手で書いたものは残ります）。`reading` はひらがな・「ー」・小文字の英字だけ（スペースや「～」は打たないので入れない）。

### 絵を入れる

`Assets/Resources/Art/` に `room.png`（マイルームの背景）、`character.png`（キャラ）、`target.png`（目標商品）を置くと、その画面に出ます。
ない絵は色つきの四角で代わりに出ます。素材を使ったら `CREDITS.md` に出典と利用規約を書いてください。

### 日本語フォントについて

WebGL ビルドでは日本語フォントを同梱する必要があります。
`Assets/Resources/Fonts/main.ttf` に **PixelMplus12 Regular**（M+ FONT LICENSE、商用・改変・再配布可）を入れてあり、すべての画面がこれを使います。
ドットをくっきり出すため、インポート設定の Rendering Mode は Hinted Raster にしています。
このフォントは12ドットで作られているので、12・24・36 の大きさがいちばんきれいです（いまの画面の文字サイズ合わせは「見た目の試作」で行います）。
フォントにない文字（「−」「〜」など）は表示されないので、全角の「－」「～」を使ってください。

## フォルダー構成

- `Assets/Scripts/Core` … ローマ字判定・評価・価格計算、財布・カート・会計・返品、日付・在庫・満足度・家計簿・セーブの中身（`Life/`・`Save/`）。Unity に依存しない C#。
- `Assets/Scripts/Game` … 画面と進行。`ShoppingFlow` が進行役（タイトル → 月初 → マイルーム ⇄ 買い物 → 夜 → 月末）で、`Screens/` に各画面、`Ui/` に共通部品。
- `Assets/Resources/Data` … 商品・文章・店舗・調整値の JSON。
- `Assets/Resources/Art` … 絵の置き場所（まだ空）。
- `Assets/Tests/EditMode` … Core のテスト。
- `tools/CoreTests` … 同じテストを Unity なしで動かす .NET プロジェクト。

## テスト

- Unity：Window > General > Test Runner の EditMode。
- Unity なし：`dotnet test tools/CoreTests`（.NET 8 SDK が必要）。GitHub Actions でも自動実行。
