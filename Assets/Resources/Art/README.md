# 絵の置き場所

ここに PNG を置くと、その画面に出ます。置いていない絵は、色つきの四角と名前が代わりに出ます。

| ファイル名 | 使う画面 | 目安のサイズ |
| --- | --- | --- |
| `room.png` | マイルームの背景 | 420×300（ドット絵なら 140×100 を3倍） |
| `character.png` | マイルームのキャラ | 128×170 |
| `target.png` | 月初の目標商品 | 200×200 |

- ドット絵がにじまないよう、表示は Point（点のまま拡大）にしています。
- 素材を使ったら、リポジトリ直下の `CREDITS.md` に出典と利用規約を書いてください。
